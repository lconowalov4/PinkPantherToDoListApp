This is a Pink Panther-style to-do list app designed to practice the MERN stack (MongoDB, Express.js, React.js, Node.js).

To run the application, you need to install MongoDB, Express.js, React.js, and Node.js.

The project is divided into two parts: the server and the application.

To start the server, open the console and navigate to the server folder:

```cd Server```

In the server folder, enter the command:

```npm run start```

To run the application in the project folder, enter the command in the console:

```npm run dev```

You also need to run the MongoDB launch command in the console:

```sudo systemctl start mongod```
